# AI usage

ETHGlobal asks every team to document where and how AI tools were used. We used Claude Code (model Claude Opus 5.5) as an orchestrator with one subagent per area. Every prompt the team gave is in docs/prompts, and every agent definition is in .claude/agents. Team decisions are recorded by hand in docs/decisions.md, which no agent edits.

## Team

1. First idea (Sluice, a research integrity oracle): product rules, stack, phases and style rules written by the team (docs/prompts/01_orchestration.md).
2. Partner prize choice, chain choice, scope cuts: decided by the team after reading the AI drafted event brief (docs/prompts/03_phase0_go.md).
3. Scope change to Bulkhead, an npm circuit breaker: product, safety rules, design rules, structure and phases written by the team (docs/prompts/bulkhead.md).

## Event brief

1. docs/event_brief.md: AI generated from the ETHGlobal Mumbai pages, read in the team's logged in browser. Team reviewed it and chose targets.
2. docs/rules.md: AI generated from the same pages, then updated with the team's decisions.

## Sluice, archived

1. Phase 0 of Sluice (root config, shared package, architecture, seven agent files, CLAUDE.md) was AI generated and reviewed by an AI reviewer agent. It is kept in git history under the tag sluice_archived.
2. On the scope change the AI removed the Sluice shared package, architecture and agent files from the working tree, on the team's instruction. No Sluice contracts, services or web code had been written.

## Bulkhead, Phase 0

1. docs/prompts/bulkhead.md: the team's prompt, saved word for word.
2. CLAUDE.md: AI generated. Style rules and slop list copied word for word from the team's prompt; product, safety and design rules condensed from docs/prompts/bulkhead.md.
3. README.md stub, package.json, pnpm-workspace.yaml, .npmrc, .gitignore, .env.example: AI generated. The workspace excludes demo/poisonedPackage and disables install scripts.
4. docs/rules.md: stack section updated by AI for the scope change.
5. packages/shared/src (constants, schemas, types, hashing, chain, abis/sealRegistry, hashing tests): AI generated.
6. docs/architecture.md: AI generated. Interface choices made by the AI and open for team review: nobody holds the admin role, so detectors and quorum are fixed per deployment; a vote that would exceed the daily seal limit reverts; votes on an Unsealed key revert so only the guardian can reseal; the watcher is the only timeline writer; demo quorum 2 of 3.
7. .claude/agents (contracts, detectors, watcher, guard, dashboard, research, reviewer, docs): AI generated from the team's agent list.
8. An AI reviewer agent audited Phase 0 and reported 24 findings. The AI applied 21 of them to the architecture, shared package, env, workspace, agent files and README. The AI applied them on its own judgment; the team has not reviewed them yet. Three that touch CLAUDE.md wait for the team.
9. After the team approved Phase 0: the AI edited CLAUDE.md (cut order, missing design rules, name exceptions), made replay timeline only in the shared schemas and architecture, and wrote docs/research/incidents.md on the TanStack incident. The team told it which sources to use and that the incident was verified; the AI found the links by web search.
10. Team decision on 6 Nov 2026: age fallback instead of fail open or closed, N placeholder 3, persistence and IDE or agent hook removal before token revocation. The AI applied it to CLAUDE.md, the architecture, the shared schemas, the guard agent file and the research note.
